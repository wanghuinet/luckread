- 日期：2026-11-27

## 1. 评审目标与百分比标准

以 X / Threads 的成熟用户体验为参考，不以“页面存在”或“代码已实现”判定完成。评审视觉布局、交互路径、功能闭环、状态处理、性能、可访问性及跨端一致性。

| 完成度 | 标准 |
|---|---|
| 100% | 对标体验达到成熟产品标准，核心/边缘状态、交互、视觉、反馈及可访问性均验证通过 |
| 90–99% | 基本达到成熟产品体验，仅有低影响细节差距 |
| 80–89% | 功能完整度较高，但细节、交互反馈、布局或异常状态有差距 |
| 60–79% | 基本可用，仍存在显著欠缺或体验断点 |
| 低于 60% | 缺失、未接入、路径断裂或明显不成熟 |

评分仅在检查实际源码、自动化运行、目标构建、设备操作及数据闭环等证据后填写。未检查项标记为 NOT REVIEWED；代码有但未运行标记 SOURCE ONLY / NOT VERIFIED；禁止虚构分数。

### 第三端

## 4. App 页面与交互评审矩阵（主审清单）

每项按 100% 体验标准检查并登记差距、证据、严重度、责任目录、验收条件。

### 4.1 Shell / 导航
- Tab 的顺序、图标、标签、选中态、触控面积、切换动画及状态保持。
- Drawer / 菜单打开、关闭、系统返回、手势返回和弹层返回一致性。
- Feed 切换 Tab 后的滚动位置、筛选、刷新状态是否按产品约定保留。
- 页面层级、返回路径、深链、外部链接和登录跳转后的 return-to。
- Modal、Bottom Sheet、键盘、安全区、滚动与层叠关系。
- 空、加载、错误、离线、权限拒绝、刷新和重试状态。

### 4.2 Home / Feed
- For You / Following（及产品实际支持的流）切换。
- 首屏骨架与加载；首次可见内容；刷新、分页、重复项与空数据。
- 新内容提示而非打断阅读；滚动位置保持。
- 头像、用户名、认证标识、时间、正文、媒体、链接、标签、引用等卡片布局。
- 文本展开/折叠、媒体尺寸、图片加载/错误、视频、GIF、轮播、无障碍文本。
- 点赞、回复、转发/引用、收藏、分享、更多菜单反馈、失败回滚与计数。
- 内容被删、被屏蔽、权限变化、作者信息变化、缓存失效的处理。
- 列表性能、虚拟化、滚动掉帧、内存与图片缓存。

### 4.3 发布 / Composer
- 从各页面入口打开、关闭、返回、草稿保留与恢复。
- 文本输入、计数、输入法、粘贴、换行、链接、表情和多语言。
- 图片/视频选取、权限、上传进度、取消、重试、预览、排序、删除、alt text。
- 多条线程、引用、回复对象、草稿、发布按钮状态及重复提交保护。
- 发布成功/失败的状态、页面跳转、Feed 同步和数据刷新。
- 网络中断、后台切换、超时与服务端成功但客户端未收到结果的恢复。

### 4.4 Post Detail / Reply
- 帖子上下文、引用链、回复树、父回复及定位。
- 回复排序、切换、加载更多、分页与无回复状态。
- 回复创建、编辑、删除、点赞、举报、引用及作者权限。
- 详情页返回 Feed 后的状态/位置。
- 失效链接、删除内容、隐私限制和账号切换。

### 4.5 Search / Explore
- 输入、清除、历史、建议、搜索提交、空/错误状态。
- 搜索类别、结果分页、筛选和排序。
- 用户、帖子、媒体及其他实际支持的搜索内容。
- 键盘、取消、返回与导航路径。
- 搜索结果的真实数据、权限过滤和响应时间。

### 4.6 Notifications
- 分类/筛选、未读标识、批量已读或清理（仅检查实际能力）。
- 聚合通知、通知卡片、关联内容与用户。
- 点击通知的正确目标及返回路径。
- App 内通知与 OS 推送权限分开管理。
- 推送禁用、权限拒绝、设备不支持、Token 失效及错误反馈。
- 无通知、加载、刷新、分页和账号隔离。

### 4.7 Messages / Chat
- 会话列表、未读、置顶/排序、搜索（如支持）、空状态。
- 单聊、群聊、消息请求、权限、成员和会话隔离。
- 发送文本/媒体、发送中、成功、失败、重试、重复发送保护。
- 长按操作、回复、删除、举报、屏蔽、已读、时间和排序（按当前产品支持）。
- 消息详情与列表同步、通知跳转、后台恢复及跨账号缓存隔离。
- 弱网、断网、重连、离开/重进和会话状态恢复。
- 键盘、输入框、滚动到底、历史加载、手势和安全区。

### 4.8 Profile / User
- 头像、头图、名称、用户名、简介、链接、认证及资料布局。
- 关注/取消、关注状态、关注/粉丝列表和计数。
- Posts / Replies / Media / Likes 等现有标签或栏目。
- 个人资料编辑、上传、保存、失败和重新读取。
- 个人页分享、公开访问、登录态、被屏蔽/隐私限制。
- 自己与他人主页的操作菜单差异。

### 4.9 设置（重点）
- 入口可发现性、层级、标题、分组、返回路径、页面一致性。
- 账号与登录：账号身份、切换、添加/移除账号、退出、会话恢复。
- 安全：会话、设备、登录/验证相关入口，必须按真实能力验收。
- 隐私：可见性、互动、发现、消息权限等，未接入控制不可伪装。
- Block / Mute：列表、解除、确认、服务端结果和内容过滤。
- Notifications：类别设置、设备推送与 OS 权限区分。
- Appearance：Light / Dark / System，保存、重启和全页面覆盖。
- Content：隐藏词、内容过滤等现有能力与缺失项分离。
- Media / Data usage：自动播放、缓存、媒体质量/数据设置（按已支持范围）。
- Accessibility：文字、对比度、触控、屏幕阅读器、减少动态效果。
- Data / Account lifecycle：导出、停用、删除等入口及真实后端闭环。
- Help / Support / Report：入口、提交、反馈状态及可达性。
- About：版本、条款、隐私政策、许可信息。
- 每个设置项检查加载、当前值、保存中、成功、失败、重试、禁用、权限拒绝与离线状态。
- 排查占位入口、无效点击、伪开关、重复设置、状态不一致及过时文案。

### 4.10 Account isolation / multi-account
- 切换账号前后 Feed、Profile、通知、消息、草稿、搜索历史和缓存隔离。
- 账号切换过程中无旧账号数据闪现。
- 退出后清理/隔离私有数据，公开数据策略明确。
- 账号移除、添加、切换失败和当前账号被移除的处理。
- 所有写操作的身份一致性、请求取消及响应归属。

### 4.11 Media / Video
- 播放/暂停、进度、音量、字幕、画面、全屏、退出和系统返回。
- 自动播放设置、后台行为、网络条件、播放错误、重试与缓存。
- 图片加载、预加载、缩放、保存/分享、媒体权限和占位。
- 滚动列表中视频/图片的性能、内存和状态恢复。

### 4.12 App 视觉与系统适配
- iOS / Android 目标设备尺寸、动态字体、系统主题、屏幕安全区。
- 页面密度、间距、字体层级、颜色、边框、圆角、图标与交互反馈统一。
- 触控区域、无障碍 label/hint/state、屏幕阅读器顺序、键盘。
- 动画帧率、reduce motion、转场、弹层与手势冲突。
- 网络、权限、加载、错误、空状态等统一组件和文案。

## 5. H5 页面与交互评审矩阵

- Composer、媒体上传、草稿、表单验证、重复提交、异常恢复。

- 公开页面可访问、SEO/分享预览、缓存与权限边界。
- 视觉组件、交互反馈、加载/空/错误状态及 App 一致性。
- 移动浏览器安全区、键盘、固定导航、滚动和弹层。

先确认实际端的代码目录、入口、运行方式、支持设备和功能清单；随后按对应平台的第 4/5 节检查。记录与 App/H5 的能力差异，避免仅凭目录或截图判定。

## 7. 三端一致性

- 统一账号、Profile、帖子、互动计数、Block/Mute、通知、消息与设置的语义。
- 状态变更后的跨端刷新、缓存策略、权限与数据源一致。
- UI 可按端适配，但功能名称、状态、失败反馈、权限边界和用户流程保持一致。
- 端间差异需列出原因（平台能力、版本范围、发布阶段）和替代路径。
- 深链/分享在端间转换：App、H5、登录、返回和目标页面。
- 不允许某端显示成功、另一端读取不到真实状态；不允许伪造成功。

## 8. X / Threads 参考体验的前端性能目标

以下作为体验目标和测量建议，不作为未经测量的达标声明：
- 关键页面 LCP：目标 p75 < 2.5s（Web 目标）。
- 交互响应 INP：目标 p75 < 200ms（Web 目标）。
- 页面布局稳定 CLS：目标 < 0.1（Web 目标）。
- App：冷启动/热启动、首屏可交互、Tab 切换、Feed 滚动、帖子打开、Composer 打开/提交、消息发送等按目标设备建立 p50/p95 基线。
- 不以模拟器单次体验或开发模式指标代替生产构建和真实设备数据。
- 验证图片策略、列表虚拟化、网络请求并发、缓存、重复请求、过度渲染和内存。

## 10. 优先级

- P0：安全、隐私、账号隔离、数据错误、关键流程崩溃、未经授权访问、伪成功。
- P1：核心旅程阻断（启动、导航、Feed、发布、互动、Profile、消息/通知等已纳入 Beta 的能力）。
- P2：明显体验差距、视觉不一致、重要状态/恢复、性能和可访问性问题。
- P3：低影响细节、非核心动画、微调和后续增强。

## 11. 证据等级

沿用工程验收证据分层：
- L0 Source：源码、API、组件、测试文件存在。
- L1 Automated：当前目标 SHA 上实际运行通过的自动化测试。
- L2 Build：当前 SHA 的目标平台构建。
- L3 Device：真实设备、操作路径、截图/录屏、设备与系统版本。
- L4 Runtime/Data：实际 API、requestId、权威持久化与重新读取证据。

源文件或历史测试存在不等于当前运行验收。未经实际验证，不报告百分比达标。

## 12. 当前已知初步风险（源码/合同证据，不代表完整实机结论）
