### Slice 5 — Administration

### Slice 6 — Client delivery
Bind Web/H5/APP clients to the canonical API after the core API/content path has executable runtime evidence.

## 7. Reuse-first rule for 1.0

Before adding code, each slice must answer:

1. Does the current foundation already provide this capability?
2. Is that capability contract-admitted?
3. Is it already backed by valid evidence?
4. Can the current implementation be extended without introducing a second subsystem?
5. Does the change stay inside 12 Workers / 4 D1 / 25 Contract Tasks?

A `NO` answer to (2) or (3) means reconcile the gate before treating the capability as delivered.
