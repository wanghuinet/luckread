# LuckRead HTML Shell Template

This directory is a reusable public self-media platform shell template.

It is inspired by common interaction patterns found in mature creator/content platforms, including:
- compact global navigation;
- clear brand and content navigation;
- authenticated-user actions;
- responsive mobile navigation;
- utility/footer links;
- accessible focus states and semantic landmarks.

It is an original LuckRead implementation. It does not copy third-party source code, assets, logos, or proprietary styles.

## Files

- `index.html` — complete reference page.
- `header.html` — reusable header markup.
- `footer.html` — reusable footer markup.
- `css/luckread-shell.css` — reset, layout, header, footer, responsive styles.
- `js/luckread-shell.js` — mobile navigation and current-year behavior.

## 1.0 public navigation

- Home: `https://luckread.com/`
- Articles: `https://luckread.com/articles`
- Posts: `https://luckread.com/posts`
- Videos: `https://luckread.com/videos`
- Shorts: `https://luckread.com/shorts`
- Creator Center: `https://mp.luckread.com/creator-center`

This is a presentation template only. It does not define API contracts, persistence, authentication, or the 2.0 Feed/Recommendation/Search system.
